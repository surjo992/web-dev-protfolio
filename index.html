React

React is a free, open-source JavaScript library used for building user interfaces (UIs), specifically for single-page applications. It was created by Meta (Facebook) in 2013 and is currently one of the most popular tools in web development.While JavaScript handles the logic, React simplifies how you build and manage what the user actually sees on their screen.

node js

n simple terms, JavaScript was originally designed to run only inside a web browser (like Google Chrome or Mozilla Firefox). In 2009, a developer named Ryan Dahl took Google Chrome's powerful V8 JavaScript Engine and brought it outside the browser, allowing it to run directly on your computer or server. This environment is called Node.js.Because of Node.js, developers can use JavaScript to write backend (server-side) code, connect to databases, and build complete web applications using just one single programming language.

Mongodb

MongoDB is a popular, open-source, NoSQL database used to store large amounts of data.Unlike traditional databases (like MySQL or PostgreSQL) that store data in rigid tables with rows and columns, MongoDB stores data in a flexible, document-oriented format called BSON (which looks exactly like JSON objects in JavaScript).Because it uses a JSON-like format, it is the absolute perfect match for JavaScript-based technologies like Node.js, React, and Next.js (commonly known as the MERN Stack).
